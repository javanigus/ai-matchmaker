# 2026-08-01 — Narrative public profile, conversation-only AI Profile Coach

## What changed

**`docs/prd.md`:**

- **Compatibility Graph**: added "The AI Matchmaker is the only editor" — the AI Matchmaker conversation is the only interface allowed to modify the graph; editing a Public Profile section's displayed text changes only what's published, never the graph; every graph change produces a corresponding AI Memory entry explaining why.
- **Public Profile**: reframed as narrative sections the AI wrote and the user approved, not a table of raw field values. Required fields changed to Name, Age, Gender, City/State/Country, Occupation (Relationship Goals moves out of "required" and becomes its own optional narrative section, edited/approved like any other category). Turning a section's visibility off now removes it from the Public Profile entirely — not shown greyed out, not rendered at all. Removed Interests as its own category — that content is folded into the relevant narrative section (typically Lifestyle or Travel) instead.
- **AI Profile Coach**: added "AI Profile Coach never gathers information itself" — it only identifies gaps and launches or continues a conversation with the AI Matchmaker; it never asks a question or collects an answer directly. Photo suggestions are the one exception, since Learning Photos are already a separate, non-conversational input channel. Suggestions now disappear automatically once their conversation fills the gap, instead of requiring manual dismissal. Updated the example suggestions list to conversation-launching actions (Chat about Lifestyle, Talk about Family, Tell me more about Travel, Discuss Religion, Continue conversation) in place of "Answer a question" / "Expand a category."
- **How the AI-Facing Pages Fit Together**: added "The core product experience" — the closing feedback loop `Conversation → Compatibility Graph → AI-generated Profile → Recommendations → AI Profile Coach → Conversation`, with the AI Matchmaker conversation named as the only way to teach the AI anything.

**`prototype/`:**

- Redesigned `profile-view.html` (the page for viewing someone else's profile): replaced the raw "Details" table and "Interests" pill list with AI-generated narrative sections (About, Religion & Spirituality, Family, Relationship Goals, Career, Lifestyle, Travel — varies per person) plus a required-fields header row (name, age, gender, location, occupation). A section is omitted entirely when the person has kept it private, rather than shown as empty or greyed out — demonstrated on Naomi's profile, whose Family section is marked hidden.
- Restructured the `PROFILES` mock data in `app.js` with a `narrative` array per person (label + AI-written text, optional `hidden` flag) and rewrote `initProfileViewPage()` to render it. The old `details` object is left in place, unused for rendering, representing the internal structured data the Compatibility Graph would still carry for matching.
- Rewired `initProfileCoach()`: clicking a suggestion's action button no longer injects an AI-authored question straight into the transcript. It now posts the topic opener as the user's own message (the same pattern as the existing suggestion chips) and the AI replies conversationally a moment later — so every conversation is visibly user-initiated, never AI-initiated out of nowhere.
- Updated `ai-profile-coach.html`'s suggestion buttons to conversation-launching labels (Chat about Lifestyle, Chat about Money Management, Talk about Family, Tell me more about Travel, Chat about Communication Style, Discuss Religion, Continue conversation) and added an eighth "Religion & Spirituality hasn't come up in a while" suggestion so all six example action styles from the spec are represented. Photo suggestions keep their direct "Upload photos" action.
- Merged My Profile's separate "Children" and "Family" category cards into one "Family" card, since the new public-profile narrative model treats children/family-building status and family closeness as one category rather than two.

## Why it changed

Founder correction to the Phase 5 AI Profile Coach implementation: it was directly asking questions in the AI's voice via `broadcastMessage('ai', question)`, which makes AI Profile Coach a second, competing channel for teaching the AI something — contradicting "the AI Matchmaker conversation is the only source of truth." The public profile redesign extends the same "AI proposes, user approves" narrative-text principle already applied to My Profile onto the page other users actually see, and removes the last raw-data leftovers (the Details table, the Interests tag list) so the whole product is consistent about what a profile *is*: prose the AI wrote from the graph, not a form the user filled out.
